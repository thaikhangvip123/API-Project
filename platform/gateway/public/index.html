POST/webhook

            

              
Content type
Content-Type: application/json

              
Event ID
X-Webhook-Id hoặc X-GitHub-Delivery

              
Signature
X-Webhook-Signature hoặc X-Hub-Signature-256

              
Formula
sha256=HMAC_SHA256(WEBHOOK_SECRET, raw_request_body)

              
Responses
202 accepted · 200 duplicate · 401 invalid · 503 retry
